## Terms

### RADIUS
[Remote Authentication Dial-In User Service](https://en.wikipedia.org/wiki/RADIUS)

Protocol that controls network access by providing centralized authentication, authorization, and accounting ([AAA](https://en.wikipedia.org/wiki/Authentication,_authorization,_and_accounting)). Clients contact a Network Access Server ([NAS](https://en.wikipedia.org/wiki/Network_access_server)) which sends an access request to the RADIUS server. The RADIUS server verifies the request and responds with a reject, challenge, or accept message. If accounting is enabled the NAS communicates start, interim updates, and stop of a client session to the RADIUS server.

## Files

### [radiusd.conf](https://www.freeradius.org/radiusd/man/radiusd.conf.html)
Main configuration file of the [FreeRADIUS](https://www.freeradius.org/documentation/) server. It consists of configuration items, sections, and comments. Its default path is `/etc/raddb/radiusd.conf`.

#### configuration items
```
name = value

string1 = "hello world"

string2 = 'hello mom'

foo = "blah \


 blah \


 blah"
```
Note: When using continuations (\\$) any CR or LF is dropped, but all other whitespace is preserved.

#### sections
```
section {
        ...

}

section foo {
        ...

}
```

#### comments
```
# comment
```

### /etc/raddb/*
FreeRADIUS configuration file path. The main configuration file, radiusd.conf, references other files in this path by including them.

## Utilities

### radiusd
The [FreeRADIUS](https://www.freeradius.org/documentation/) server.

### [radmin](https://www.freeradius.org/radiusd/man/radmin.html)

This is the FreeRADIUS server administration tool.

### [radtest](https://www.freeradius.org/radiusd/man/radtest.html)
Frontend to radclient, generating a list of configuration options and feeding these into radclient.

### [radclient](https://www.freeradius.org/radiusd/man/radclient.html)
Client able to send arbitrary packets to a RADIUS server, and show its reply.

### [radlast](https://www.freeradius.org/radiusd/man/radlast.html)
Frontend to the host's `last` command, passing the database path and options specified on the command line.

### [radwho](https://www.freeradius.org/radiusd/man/radwho.html)
Shows the content of the session database.

### wireshark
[Wireshark](https://www.wireshark.org/docs/wsug_html/) is a graphical network packet analyzer.

### tshark
[TShark](https://www.wireshark.org/docs/man-pages/tshark.html) is a text-based network protocol analyzer. It captures packets by using the pcap library. It operates similar to `tcpdump`.

### tcpdump
[Home](https://www.tcpdump.org/) of both `tcpdump`, a command-line packet analyzer, and `libpcap`, a library for network traffic capture.

### kismet
[Kismet](https://www.kismetwireless.net/) is a sniffer, wireless intrusion prevention system ([WIDS](https://en.wikipedia.org/wiki/Wireless_intrusion_prevention_system)), and [wardriving](https://en.wikipedia.org/wiki/Wardriving) tool for Wi-Fi, Bluetooth, Zigbee, etc.

### ndpmon
Network Discovery Protocol Monitor ([NDPMon](https://sourceforge.net/projects/ndpmon/)) is used to monitor ICMPv6 packets, especially during Stateless Address Autoconfiguration ([SLAAC](https://en.wikipedia.org/wiki/IPv6_address#Stateless_address_autoconfiguration_(SLAAC))).

### aircrack-ng
[Aircrack-ng](https://www.aircrack-ng.org/) is a collection of tools for WiFi security. Its features include: monitoring, attacking, testing, and cracking.

### bettercap
A self-proclaimed Swiss Army knife for WiFi, Bluetooth Low Energy, wireless HID hijacking, CAN-bus, and IPv4/IPv6 networks inspection and [MITM](https://en.wikipedia.org/wiki/Man-in-the-middle_attack) attacks, [bettercap](https://www.bettercap.org/) is an extensible framework written in Go.
