## Utilities

### iptables / ip6tables
Manage netfilter rules

### iptables-save / ip6tables-save
Dump active netfilter rules

### iptables-restore / ip6tables-restore
Install netfilter rules

### ipset
[IP Set](https://ipset.netfilter.org/) manages IP sets in the Linux kernel (IPv4 and IPv6) for use in netfilter rules

#### [Tips and Examples](https://ipset.netfilter.org/tips.html)
* use IP sets in netfilter's raw table to drop traffic to/from banned networks / IP addresses
* swap IP sets to apply changes without touching netfilter rules:

```
# Create the new set and add the entries to it
ipset -N new-set ....
ipset -A new-set ....
...

# Swap the old and new sets
ipset -W old-set new-set

# Get rid of the old set, which is now under new-set
ipset -X new-set
```

## Notes

### nftables, nft
[nftables](https://www.netfilter.org/projects/nftables/index.html) replaces {ip,ip6,arp,eb}tables by providing a new in-kernel packet classification framework based on a network-specific VM, and a new command: `nft`

### ebtables
[ebtables](https://ebtables.netfilter.org/) is the legacy command for managing [bridge](https://wiki.linuxfoundation.org/networking/bridge) tables, it is superseded by nftables

### conntrackd
[conntrackd](https://conntrack-tools.netfilter.org/conntrackd.html) is the netfilter connection tracking userspace daemon
